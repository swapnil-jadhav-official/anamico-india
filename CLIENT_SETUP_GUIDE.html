📊 Analytics & SEO Setup Guide

ANAMICO India - Complete Configuration Instructions

👋 Welcome!

This guide will help you complete the final configuration steps for your website's analytics and SEO setup. The technical implementation is already complete - you just need to configure your Google accounts.

Total Time Required: Approximately 30 minutes

What You'll Set Up:

  • Google Analytics 4 (GA4) - Track website visitors and behavior
  • Google Search Console - Monitor search performance and indexing
1

Google Analytics 4 Setup

⏱️ Estimated time: 15 minutes
1.1

Create Google Analytics Account

Go to: https://analytics.google.com

  • Sign in with your Google account
  • If you already have a Google Analytics account, skip to step 1.2
  • If this is your first time, click "Start measuring" button
1.2

Create GA4 Property

In Google Analytics Dashboard:

  • Click the Admin gear icon (⚙️) at the bottom left
  • In the "Property" column, click "Create Property"
  • Property name: Enter "ANAMICO India"
  • Reporting time zone: Select "India - India Standard Time"
  • Currency: Select "Indian Rupee (₹)"
  • Click "Next"
1.3

Business Information

Fill in the details:

  • Industry category: Select "Shopping" or "Technology"
  • Business size: Select appropriate size
  • How you intend to use Google Analytics: Check all relevant options
  • Click "Create"
  • Accept the Terms of Service
1.4

Set Up Data Stream

Choose platform:

  • Click "Web" platform
  • Website URL: Enter https://amicocart.com
  • Stream name: Enter "ANAMICO India Website"
  • Enable "Enhanced measurement" (recommended)
  • Click "Create stream"
1.5

Copy Measurement ID

Get your tracking code:

✅ Important!

You'll see your Measurement ID at the top right. It looks like this:

G-XXXXXXXXXX

Copy this ID - you'll need it in the next step!

1.6

Add Measurement ID to Server

Connect to your server:

ssh root@212.38.94.61

Password: Pawan@@112233

Once connected, edit the .env file:

cd /var/www/app
nano .env

Add this line at the end of the file:

NEXT_PUBLIC_GA_MEASUREMENT_ID=G-XXXXXXXXXX
⚠️ Important:

Replace G-XXXXXXXXXX with your actual Measurement ID from step 1.5

Save and exit:

  • Press Ctrl + X
  • Press Y to confirm
  • Press Enter to save
1.7

Restart Application

Still connected to the server, run:

source ~/.nvm/nvm.sh
pm2 restart amicocart
✅ Success!

Google Analytics 4 is now tracking your website! Data will appear in your GA4 dashboard within 24-48 hours.

1.8

Verify Tracking (Optional)

To verify it's working:

  • Visit https://amicocart.com
  • Go back to Google Analytics dashboard
  • Click "Reports" → "Realtime"
  • You should see yourself as an active user!
ℹ️ Note:

Real-time data appears within 1-2 minutes. Historical reports take 24-48 hours to populate.

✅ Google Analytics 4 Checklist

2

Google Search Console Setup

⏱️ Estimated time: 15 minutes
2.1

Access Google Search Console

Go to: https://search.google.com/search-console

  • Sign in with your Google account (same as GA4)
  • Click "Start now" if it's your first time
2.2

Add Property

Choose property type:

  • Click "Add property" (top left)
  • Select "URL prefix" option (not Domain)
  • Enter: https://amicocart.com
  • Click "Continue"
2.3

Verify Ownership - HTML Tag Method

Choose verification method:

  • Click on "HTML tag" tab
  • You'll see a meta tag like this:
<meta name="google-site-verification" content="abc123xyz..." />
⚠️ Important:

Copy the content value (the part after content="..."). You'll need this verification code.

2.4

Add Verification Code to Website

Connect to your server:

ssh root@212.38.94.61

Edit the layout file:

cd /var/www/app
nano app/layout.tsx

Find the "verification" section and add your code:

Look for this section:

verification: {
// google: 'your-verification-code',
},

Replace it with:

verification: {
google: 'abc123xyz...', // Your actual code here
},
ℹ️ Tip:

Remove the // and replace your-verification-code with the code you copied from Search Console.

Save and exit:

  • Press Ctrl + X
  • Press Y to confirm
  • Press Enter to save
2.5

Build and Restart

Rebuild the application with new verification code:

cd /var/www/app
npm run build
source ~/.nvm/nvm.sh
pm2 restart amicocart
ℹ️ Note:

The build process may take 2-3 minutes. Wait for it to complete before proceeding.

2.6

Complete Verification

Go back to Google Search Console:

  • Click the "Verify" button
  • If successful, you'll see a success message!
  • If it fails, wait 2-3 minutes and try again
✅ Verified!

Your property is now verified in Google Search Console.

2.7

Submit Sitemap

After verification:

  • In Google Search Console, go to "Sitemaps" (left sidebar)
  • In the "Add a new sitemap" box, enter: sitemap.xml
  • Click "Submit"
✅ Sitemap Submitted!

Google will start indexing your pages within 24-48 hours.

2.8

Request Indexing (Optional)

To speed up indexing:

  • Go to "URL Inspection" (left sidebar)
  • Enter your homepage URL: https://amicocart.com
  • Click "Request Indexing"
  • Repeat for important pages (product pages, about, contact)
ℹ️ Note:

You can request indexing for up to 10 URLs per day. Prioritize your most important pages.

✅ Google Search Console Checklist

3

Verify Everything is Working

⏱️ Estimated time: 5 minutes
3.1

Test SEO Files

Open these URLs in your browser:

  • https://amicocart.com/robots.txt - Should show crawling rules
  • https://amicocart.com/sitemap.xml - Should show XML sitemap
3.2

Test Rich Results

Check if product schema is working:

  • Go to: Google Rich Results Test
  • Enter a product page URL (e.g., any product from your site)
  • Should detect "Product" schema with price and availability
3.3

Check Analytics Tracking

Verify GA4 is tracking:

  • Visit your website
  • Open browser DevTools (F12)
  • Go to Network tab
  • Filter for "google-analytics" or "gtag"
  • You should see requests being sent

OR check GA4 real-time:

  • Go to Google Analytics dashboard
  • Click "Reports" → "Realtime"
  • Visit your website in another tab
  • You should appear as an active user

Troubleshooting

Problem: Can't see analytics data

Solution:

  • Wait 24-48 hours for data to appear
  • Check if Measurement ID is correct in .env file
  • Verify application was restarted after adding ID
  • Use Realtime reports to see immediate data

Problem: Search Console verification fails

Solution:

  • Verify the code was added correctly in layout.tsx
  • Check that you rebuilt the application (npm run build)
  • Wait 2-3 minutes after restart before verifying
  • Try verifying again - sometimes it takes a moment

Problem: Sitemap not found

Solution:

  • Visit https://amicocart.com/sitemap.xml directly
  • If it shows 404, the build might have failed
  • Run npm run build again on server
  • Restart with pm2 restart amicocart
